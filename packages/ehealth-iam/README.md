# ehealth-iam

A library to give you proper type support for eHealth's quirky OIDC implementation.
Based on the documentation at https://ehealth.fgov.be/ehealthplatform/file/cc73d96153bbd5448a56f19d925d05b1379c7f21/9a7dc4d16e58378f81f999fc3a5333448bcdec8b/iam-mobile-integration-tech-specs-v1-13.pdf

## Building

Run `nx build ehealth-iam` to build the library.

## Running unit tests

Run `nx test ehealth-iam` to execute the unit tests via [Vitest](https://vitest.dev/).
